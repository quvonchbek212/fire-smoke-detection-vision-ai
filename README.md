# 🔥 Fire & Smoke Detection Vision AI

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://python.org)
[![YOLO11](https://img.shields.io/badge/Model-YOLO11m-orange.svg)](https://ultralytics.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Real-time industrial fire and smoke detection system powered by fine-tuned YOLO11 / YOLOv8 models.

## 🌟 Key Capabilities

* **Real-Time Detection:** Rapidly detects fire and smoke hazards under 10ms.
* **Multi-Source Support:** Works with RTSP streams, USB webcams, and video files.
* **REST API & Studio:** Includes FastAPI testing endpoints and interactive web preview.

## 🚀 Quickstart

```bash
git clone https://github.com/quvonchbek212/fire-smoke-detection-vision-ai.git
cd fire-smoke-detection-vision-ai
pip install -r requirements.txt
python app.py
```
